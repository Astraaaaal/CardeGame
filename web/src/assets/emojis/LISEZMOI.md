# Emojis du jeu

Déposer ici les images des emojis (PNG, GIF, WebP ou SVG, carrées, 64×64 px conseillé).

- Le **nom du fichier** devient le code de l'emoji : `dragon.png` → `:dragon:`.
- Noms en minuscules, chiffres et `_` uniquement (pas d'espace ni d'accent).
- Un nouvel emoji apparaît dans le sélecteur 🙂 après un commit + déploiement.

Les emojis `coeur`, `etoile`, `feu` et `sourire` sont provisoires (tests) : à remplacer ou supprimer.
